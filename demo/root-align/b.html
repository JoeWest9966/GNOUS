覆盖范围

按功能域折叠单元细节

音频

音量条、设置 → 声音面板、系统提示音、应用录音与语音通话。对应 pipewire / pipewire-pulse / wireplumber / filter-chain。

媒体控制

媒体播放键、GNOME 媒体指示器、蓝牙耳机播放控制。对应 mpris-proxy.service。

全局搜索

GNOME 概览搜索本地文档内容。对应 localsearch-3.service（Tracker 文件索引）。

作用域

只写 /root/.config/systemd/user；不改 /usr/lib，不 enable/disable 全局单元，joe 会话完全不受影响。

危险操作 · 独立区域

重启 GNOME Shell 会让当前会话短暂中断；应用后音量条不立即出现时才需要。UI 默认不触发，需二次确认。

巨型状态与胶囊只显示真实 `status` 结论；工具缺失、命令失败时显示 UNKNOWN / FAILED 及原样 stdout，绝不伪造绿灯。`revert` 删除覆盖目录并清理 state.json。
