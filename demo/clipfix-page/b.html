三步生效

不落系统文件 · 随时回退
01

体检

抓 XGetSelectionOwner 与 WAYLAND_DEBUG，确认剪贴板坏在 compositor 层，并记录终端当前后端。

运行 check.sh
02

加固

写入 GDK_BACKEND=x11 到 user 环境变量，不碰任何进程、不写系统文件，gtk 应用下次启动即生效。

应用补丁
03

重启终端

已运行的 gnome-terminal-server 需要重启才会读新环境变量，会关掉所有终端窗口，请先保存工作。

重启终端 server

补丁不能「修好」Wayland 剪贴板 —— 用户态拦不住「应用 → compositor」这一步。它只是把终端绕到 X11 通道，想真正恢复必须重启图形会话。
