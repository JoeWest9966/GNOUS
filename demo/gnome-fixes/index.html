做了什么

把 gsettings 代理与 shell 环境变量双向同步，避免 GUI 能上网、终端不能（或反之）。

gsettings set org.gnome.system.proxy mode 'manual'

这些都不是「根治」：每项只是把受影响的程序绕到没坏的通道，或补齐缺失的启动项。所有改动不写系统文件，随时可回退；涉及会话的改动会标注「需重登」。
