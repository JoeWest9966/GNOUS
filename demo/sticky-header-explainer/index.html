表头吸顶是什么？

表头吸顶（sticky header）指：表格内容向下滚动时，写着「进程 / 状态 / CPU / 内存」的那一行 始终钉在可视区顶部，不跟着滚走。这样滚到第 80 行时，你仍然知道每个数字是哪一列； 不吸顶的话，滚过去以后表头就消失了，只剩一串没有标签的数字。 两侧都可以滚动，请分别向下滚动对比。
